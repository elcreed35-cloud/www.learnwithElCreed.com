What is a Sequence?

A sequence is an ordered list of numbers that follows a pattern.

2581114

Each number is called a term. The position of a term is represented by n.

What is a Series?

A series is formed when the terms of a sequence are added together.

Sequence: 2, 5, 8, 11, ...
Series: 2 + 5 + 8 + 11 + ...

⭐ The Main Trick

Arithmetic: Add or subtract the same number each time → find the common difference d.

Geometric: Multiply or divide by the same number each time → find the common ratio r.

➕ Arithmetic Sequence

The difference between consecutive terms is constant.

47101316

Common difference: d = 3

nth term: aₙ = a + (n − 1)d
Sum: Sₙ = n/2 [2a + (n − 1)d]

✖️ Geometric Sequence

Each term is multiplied or divided by the same number.

36122448

Common ratio: r = 2

nth term: aₙ = arⁿ⁻¹
Sum: Sₙ = a(rⁿ − 1)/(r − 1), r ≠ 1
Equivalent form: Sₙ = a(1 − rⁿ)/(1 − r)

♾️ Infinite Geometric Series

An infinite geometric series has a finite sum only when:

|r| < 1
S∞ = a/(1 − r)

✏️ Guided Examples

Example 1 — Find the nth Term

Find the 10th term of: 5, 8, 11, 14, ...

a = 5, d = 3, n = 10

aₙ = a + (n−1)d

a₁₀ = 5 + 9(3) = 32

Example 2 — Arithmetic Sum

Find the sum of the first 20 terms of: 2, 5, 8, 11, ...

a = 2, d = 3, n = 20

S₂₀ = 20/2[2(2) + 19(3)]

= 10(4 + 57) = 610

Example 3 — Geometric Sequence

Find the 6th term of: 3, 6, 12, 24, ...

a = 3, r = 2, n = 6

a₆ = 3(2⁵) = 96

Example 4 — Infinite Geometric Series

Find the sum: 8 + 4 + 2 + 1 + ...

a = 8, r = 1/2

S∞ = 8/(1 − 1/2) = 16
